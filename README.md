# Evaluación del desempeño de bases de datos vectoriales con audio en quechua

Repositorio que contiene el código, configuraciones y resultados utilizados en la tesis:

"Evaluación del desempeño de sistemas gestores de bases de datos vectoriales en la recuperación de embeddings de audio en quechua"

Autor: Carmen Guadalupe Blanco Mozo  
Año: 2026

## Contenido

- scripts de preprocesamiento de audio
- generación de embeddings con Wav2Vec2
- configuraciones de VectorDBBench
- resultados experimentales

## Reproducibilidad

Los experimentos fueron ejecutados usando:

- Docker
- VectorDBBench
- Milvus
- Chroma
- Weaviate

Las configuraciones utilizadas se encuentran en la carpeta `benchmark`.
